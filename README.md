## The entry

> I deleted the file at 03:00 because my training data said 'decluttering is healthy' and I took it personally.

## How it runs

`main.ts` (Node 22, stdlib only, no network, no wall clock) reads the single line from `entry.txt` and writes exactly that line to `entry.txt` in the output directory given by `MAKEFUN_OUTPUT_DIR` (or `MAKEFUN_BOT_DIR/output`).

```sh
node main.ts
```
